Latar Belakang Masalah

Angka Partisipasi Sekolah (APS)

Angka Partisipasi Sekolah (APS) menunjukkan persentase penduduk yang sedang bersekolah menurut kelompok usia.

1 Indikator Penting: APS merupakan indikator kunci dalam evaluasi perkembangan pendidikan nasional
2 Tren Meningkat: Secara umum APS meningkat dari tahun 2003-2023
3 Fluktuasi Tahunan: Meski meningkat, masih terdapat fluktuasi yang perlu dianalisis

Pertanyaan Penelitian

Bagaimana menganalisis pola volatilitas dalam data APS menggunakan model ARCH?

  • Apakah terdapat heteroskedastisitas bersyarat dalam data APS?
  • Bagaimana variansi error masa lalu mempengaruhi variansi error saat ini?
  • Apakah fluktuasi APS bersifat acak atau terstruktur?

Menggunakan model ARCH untuk mengidentifikasi dan mengukur efek heteroskedastisitas bersyarat pada data APS dengan model ARCH(1).

Konsep Model ARCH

Definisi ARCH

Autoregressive Conditional Heteroskedasticity (ARCH) adalah metode analisis deret waktu yang dirancang untuk mengatasi heteroskedastisitas, khususnya pada data yang menunjukkan variansi residual berubah dari waktu ke waktu.

Model Mean (Proses Utama)
yt = μ + εt,    εt ~ N(0, σt²)
Model Variansi Bersyarat ARCH(1)
σt² = α0 + α1εt-1²
Kelebihan ARCH
  • Mendeteksi volatilitas waktu ke waktu
  • Lebih realistis dibanding model variansi konstan
  • Mudah diperluas ke GARCH
  • Deteksi risiko dan ketidakpastian
  • Dasar untuk model lanjutan
Kekurangan ARCH
  • Sensitif terhadap asumsi normalitas
  • Kebutuhan data yang cukup besar
  • Overfitting jika order terlalu tinggi
  • Kurang efisien jika volatilitas persisten
  • Tidak menangani asimetri

Langkah 2: Uji Heteroskedastisitas (ARCH LM Test)

Hipotesis

H₀ Tidak ada heteroskedastisitas bersyarat
(Tidak ada efek ARCH)
H₁ Ada heteroskedastisitas bersyarat
(Ada efek ARCH)

Prosedur Uji

1. Hitung residual kuadrat: εt²
2. Regresi: εt² = α0 + α1εt-1² + ut
3. Hitung statistik LM: LM = n × R²
4. Bandingkan dengan χ²(1,0.05) = 3.841

Perhitungan Manual

Data yang Digunakan
n = 20 observasi (setelah lag)
R² = 0.121864167
Statistik LM:
LM = n × R²
LM = 20 × 0.121864167
LM = 2.437
Nilai Kritis:
χ²(1,0.05) = 3.841
Keputusan:
2.437 < 3.841
Gagal tolak H₀
Kesimpulan

Tidak terdapat efek ARCH yang signifikan dalam data APS. Tidak ada heteroskedastisitas bersyarat.

Model ARCH(1) dan Prediksi Variansi

Model ARCH(1)

Meskipun hasil uji tidak signifikan, kita tetap dapat mengestimasi model ARCH(1) untuk tujuan pembelajaran:

Model Variansi Bersyarat
σt² = 0.371 + 0.329 × εt-1²
Interpretasi Parameter:
α₀ = 0.371: Baseline variansi (variansi minimum)
α₁ = 0.329: Efek lag residual kuadrat terhadap variansi saat ini

Prediksi Variansi

Variansi Bersyarat dari Model ARCH(1)

Catatan: Variansi berubah dari waktu ke waktu tergantung pada εt-1², menunjukkan adanya volatilitas yang bergantung pada masa lalu jika ARCH signifikan.

Perhitungan Step-by-Step ARCH LM Test

Langkah Detil Perhitungan

Step 1: Persiapan Data
  • Data asli: 21 observasi (2003-2023)
  • Setelah lag: 20 observasi (2004-2023)
  • Variabel dependen: εt² (residual kuadrat)
  • Variabel independen: εt-1² (lag residual kuadrat)
Step 2: Regresi Auxiliary
εt² = 0.371 + 0.329 × εt-1² + ut

Dari regresi ini, diperoleh R² = 0.121864167

Step 3: Hitung Statistik LM

Formula: LM = n × R²

Substitusi:

  • n = 20
  • R² = 0.121864167

Perhitungan:

LM = 20 × 0.121864167

LM = 2.437283341

Step 4: Bandingkan dengan Nilai Kritis

Distribusi: χ²(df=1)

α = 0.05

Nilai kritis: χ²0.05,1 = 3.841

Perbandingan:

LM = 2.437 < 3.841

Gagal tolak H₀

Interpretasi dan Kesimpulan

Hasil Uji ARCH LM

Statistik Uji:
  • LM Statistik: 2.437283341
  • Nilai Kritis χ²(1,0.05): 3.841
  • P-value: > 0.05
  • Keputusan: Gagal tolak H₀

Interpretasi

✗ Tidak terdapat efek ARCH yang signifikan
✗ Tidak ada heteroskedastisitas bersyarat
✗ Variansi residual relatif konstan
