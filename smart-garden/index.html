Pengenalan Internet of Things (IoT)

Apa itu Internet of Things (IoT)?

IoT adalah jaringan perangkat yang terhubung ke internet untuk saling bertukar data.

Statistik Terkini:

  • Lebih dari 30 miliar perangkat IoT terhubung di 2023
  • Diperkirakan meningkat hingga 75 miliar pada 2025
  • Pasar Smart Garden global bernilai USD 14,4 miliar (2023)
  • Pertumbuhan tahunan 18,6% hingga 2030

1

Sensor (mengumpulkan data) dan Aktuator (melakukan tindakan)

2

Konektivitas

WiFi, Bluetooth, ZigBee, LoRa, 5G

3

Cloud

Penyimpanan data, pemrosesan dan analisis

4

Aplikasi

Antarmuka pengguna, visualisasi data, kontrol dan monitoring

Mikrokontroler dalam Ekosistem IoT

Definisi Mikrokontroler

Mikrokontroler adalah perangkat komputasi kecil yang dapat diprogram untuk mengontrol perangkat lain.

Komponen Mikrokontroler

  • CPU: Otak mikrokontroler
  • Memori: ROM, RAM, EEPROM
  • I/O Ports: Komunikasi dengan perangkat luar
  • Timer dan Counter: Pengukuran waktu
  • ADC/DAC: Konversi sinyal analog-digital
  • Komunikasi: UART, SPI, I2C, WiFi, BLE

Fungsi Utama Mikrokontroler

INPUT

Menerima sinyal dari sensor atau perangkat lain

PROSES

Mengolah data berdasarkan kode program

OUTPUT

Mengendalikan aktuator atau perangkat lain

Jenis Mikrokontroler Populer

Arduino (AVR)
ESP8266/ESP32
Raspberry Pi Pico
STM32

ESP8266 vs ESP32: Perbandingan

Fitur ESP8266 ESP32
CPU Single-core 80MHz Dual-core 240MHz
WiFi 2.4 GHz 2.4 GHz
Bluetooth Tidak ada BLE & Classic
GPIO ~11 pin 36+ pin
ADC 1 channel (10-bit) 18 channels (12-bit)
Harga $2-4 (Rp 25.000 - 50.000) $3-10 (Rp 45.000 - 150.000)
RAM ~50KB 520KB

ESP8266: Pilihan Ekonomis

Cocok untuk proyek IoT sederhana dengan kebutuhan konektivitas WiFi dan pengukuran sensor terbatas. Ideal untuk pemula dan proyek dengan budget terbatas.

ESP32: Lebih Bertenaga

Lebih cocok untuk proyek kompleks yang memerlukan koneksi Bluetooth, banyak sensor, atau pemrosesan data yang lebih intensif.

Pengenalan ESP8266

Apa Itu ESP8266?

ESP8266 adalah modul WiFi berbasis mikrokontroler dengan harga terjangkau yang dibuat oleh Espressif Systems.

Kelebihan ESP8266:

  • Mendukung koneksi WiFi 2.4GHz
  • Hemat daya (konsumsi <1W)< /li>
  • Cocok untuk proyek IoT skala kecil-menengah
  • Harga murah (Rp 25.000 - 50.000)
  • Dukungan komunitas yang luas

Varian ESP8266

1

ESP-01

Versi kompak, 8 pin, ukuran kecil

2

NodeMCU

Development board lengkap dengan USB

3

Wemos D1 Mini

Bentuk kecil, pin kompatibel Arduino

4

ESP-12E/F

Module dengan lebih banyak GPIO

Cara Kerja ESP8266

Alur Kerja ESP8266

1

Koneksi WiFi

ESP8266 terhubung ke jaringan WiFi atau membuat access point sendiri

2

Pemrograman

Program ditulis menggunakan Arduino IDE, MicroPython, atau NodeMCU (Lua)

MQTT: Protocol for IoT

MQTT (Message Queuing Telemetry Transport) adalah protokol komunikasi ringan berbasis model publish/subscribe yang ideal untuk IoT.

Keunggulan MQTT:

  • Overhead minimal (hanya 2 bytes)
  • Mendukung Quality of Service (QoS)
  • Menyimpan pesan untuk klien offline
  • Dukungan TLS/SSL untuk keamanan
  • Ideal untuk jaringan dengan bandwidth terbatas

Komponen MQTT:

  • Broker: Server pusat (Mosquitto, HiveMQ)
  • Publisher: Pengirim data (sensor)
  • Subscriber: Penerima data (aplikasi)
  • Topic: Jalur kategorisasi pesan

Implementasi MQTT di Smart Garden

Cara Kerja MQTT

  1. Publish: Sensor mengirim data ke broker dengan topik tertentu
    PUBLISH smartgarden/sensor1/humidity 85.5
  2. Subscribe: Aplikasi mendaftar untuk menerima data dari topik
    SUBSCRIBE smartgarden/sensor1/#
  3. Quality of Service (QoS):
    • QoS 0: Kirim sekali, tidak ada konfirmasi
    • QoS 1: Kirim hingga dikonfirmasi
    • QoS 2: Pastikan diterima tepat sekali

Pengenalan Smart Garden

Apa itu Smart Garden?

Smart Garden adalah sistem berbasis IoT yang memantau dan mengontrol lingkungan tanaman secara otomatis untuk mengoptimalkan pertumbuhan dan efisiensi sumber daya.

Statistik Terkini:

  • Pasar Smart Garden Indonesia tumbuh 22% (2022-2023)
  • Penghematan air hingga 40-60% dibanding metode manual
  • ROI untuk petani kecil: 6-18 bulan

Fitur Utama Smart Garden

1

Monitoring Kondisi Tanaman

Kelembaban tanah, suhu, kelembaban udara, intensitas cahaya

2

Otomasi

Sistem pengairan otomatis, penerangan tambahan, kontrol nutrisi

3

Analisis Data

Tren pertumbuhan, prediksi kebutuhan air, deteksi anomali

Manfaat Smart Garden

Efisiensi Sumber Daya

  • Penghematan air hingga 60%
  • Pengurangan penggunaan pupuk
  • Optimalisasi energi
  • Pengairan otomatis hanya saat diperlukan

Peningkatan Produktivitas

  • Pertumbuhan tanaman optimal
  • Deteksi dini hama dan penyakit
  • Mengurangi gagal panen
  • Pengaturan kondisi ideal

Kemudahan Operasional

  • Monitoring jarak jauh
  • Notifikasi real-time
  • Mengurangi kebutuhan tenaga kerja
  • Data akses kapan saja, di mana saja

Alur Data dalam Smart Garden

  1. Sensor → ESP8266/ESP32: Sensor mengirim data ke mikrokontroler
    float humidity = dht.readHumidity();
  2. ESP8266/ESP32 → MQTT Broker: Data dikirim ke broker via WiFi
    client.publish("smartgarden/sensor1/humidity", String(humidity).c_str());
  3. MQTT Broker → Server/Cloud: Broker mendistribusikan data
  4. Server → Database: Data disimpan untuk analisis
  5. Server → Frontend: Data ditampilkan di dashboard
  6. Frontend → MQTT Broker: Perintah kontrol dari user
    client.publish("smartgarden/control/pump", "ON");
  7. MQTT Broker → ESP8266/ESP32: Perintah diterima mikrokontroler
    if (String(topic) == "smartgarden/control/pump" && String(payload) == "ON") { digitalWrite(RELAY_PIN, HIGH); }
  8. ESP8266/ESP32 → Aktuator: Mikrokontroler mengontrol pompa/solenoid

Studi Kasus

Smart Garden Skala Rumahan

  • 5-10 tanaman pot
  • Budget < Rp 500.000
  • Kontrol via smartphone
  • ESP8266 + DHT11 + 1 sensor kelembaban
  • Pompa air mini 5V
  • Power via adaptor

Vertical Garden Perkotaan

  • 50-100 tanaman
  • Multiple zone control
  • Data logging dan analisis
  • ESP32 + multiple sensor
  • Solenoid valve per zona
  • Power via listrik + solar backup

Greenhouse Komersial

  • 500+ tanaman
  • Integrasi multi-sensor
  • Prediksi ML untuk panen
  • Multiple ESP32 + Gateway
  • Sistem irigasi industri
  • Kontrol iklim komprehensif

Praktik Terbaik Smart Garden

Hardware

  • Gunakan waterproof casing untuk elektronik
  • Perlindungan terhadap arus lebih (fuse)
  • Backup power (baterai/solar panel)
  • Gunakan sensor berkualitas baik
  • Hindari koneksi langsung 220V tanpa pengalaman
  • Gunakan PCB anti korosi untuk luar ruangan

Software

  • OTA updates (Over-The-Air)
  • Failsafe mode saat internet terputus
  • Data caching untuk mencegah kehilangan data
  • Enkripsi komunikasi (TLS/SSL)
  • Watchdog timer untuk restart otomatis
  • Logging komprehensif untuk troubleshooting

Operasional

  • Kalibrasi sensor secara berkala
  • Pembersihan filter dan nozzle
  • Monitoring baterai dan power supply
  • Backup database secara reguler
  • Persiapan untuk kondisi ekstrem (banjir, listrik padam)
  • Dokumentasi lengkap sistem
