Latar Belakang dan Motivasi

Permasalahan ELM Tradisional

Sensitivitas Inisialisasi: Performa bergantung pada bobot acak yang dihasilkan
Variabilitas Hasil: Output bervariasi signifikan antar sesi training
Solusi Suboptimal: Moore-Penrose inverse mungkin tidak mencapai global optimal
Overfitting Risk: Terutama pada dataset kecil

Solusi yang Diusulkan

Integrasi Metaheuristik

Menggunakan algoritma optimasi metaheuristik untuk mengatasi masalah random weight initialization

Algoritma Matematis

Menggunakan PSS, INFO, dan RUN yang berbasis matematika untuk foundation yang lebih robust

Aplikasi Real-world

Testing pada data aliran sungai Nil dengan 130 tahun data historis

"Penelitian ini memperkenalkan tiga algoritma optimisasi matematis terdepan (PSS, INFO, RUN) yang mengatasi kelemahan fundamental ELM tradisional dalam penentuan bobot secara acak."

- Van Thieu et al., Scientific Reports 2024

Metodologi Penelitian

Dataset dan Studi Kasus

Lokasi Penelitian

Aswan High Dam, Mesir

Sungai Nil - reservoir terbesar untuk kontrol banjir, pembangkit listrik, dan irigasi

Data Historis

130 tahun (1870-2000)

Data aliran bulanan dari Kementerian Sumber Daya Air Mesir

Pembagian Data

80% Training - 20% Testing

Cross-validation dengan 10 runs untuk reliability

Arsitektur ELM

Input Layer

6 nodes

Selected lag features (Q(t-1), Q(t-11), Q(t-12), Q(t-13), Q(t-23), Q(t-24))

Hidden Layer

2*si + 1 nodes

ELU (Exponential Linear Unit) activation function

Output Layer

1 node

Streamflow prediction Q(t)

Feature Selection

ANOVA F-test digunakan untuk menentukan lag features optimal. Dari 24 lag features yang tersedia, dipilih 6 features dengan nilai F-test tertinggi untuk prediksi satu bulan ke depan.

Algoritma Metaheuristik yang Diusulkan

PSS

Pareto-like Sequential Sampling

Prinsip Kerja:
  • Design-of-experiment methods
  • Monte Carlo & Latin hypercube sampling
  • 80/20 analogy acceptance probability
  • Resampling pada prominent domain
Keunggulan:
  • Exploration capability yang kuat
  • Simplicity dalam implementasi
  • Proven performance pada engineering problems

INFO

Weighted Mean of Vectors

Komponen Utama:
  • Updating Rule Phase
  • Vector Combining Phase
  • Local Search Phase
  • Weighted mean dari random vectors
Keunggulan:
  • Solid mathematical foundation (400+ citations)
  • Balance optimal exploration-exploitation
  • Effective di engineering applications

RUN

Runge-Kutta Optimizer

Inspiration:
  • Metode Runge-Kutta untuk ODE
  • Search mechanism based theory
  • Enhanced solution quality phase
  • Adaptive control factor w
Advantages:
  • Metaphor-free population approach
  • Mathematical foundation yang kuat
  • Proven efficiency pada real-world problems
Parameter Settings
Population Size: 50
Function Evaluations: 50,000
Search Space: [-1, 1]
Fitness Function: Average RMSE
